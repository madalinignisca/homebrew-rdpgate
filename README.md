# homebrew-rdpgate

Homebrew tap for [RDPGate](https://github.com/madalinignisca/rdpgate), a macOS
menu-bar launcher for FreeRDP.

```sh
brew install --cask madalinignisca/rdpgate/rdpgate
```

Apple Silicon, macOS 14 or newer. FreeRDP is installed as a dependency.

The cask is updated by `publish.sh` in the RDPGate repository; edit it by hand
only to change its structure.
